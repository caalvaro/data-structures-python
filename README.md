# Installation

## Create venv

```bash
python3 -m venv .venv
```

## Activate virtual environment

On Linux

```bash
source .venv/bin/activate
```

## Install requirements

```bash
pip install -r requirements.txt
```

# Compile documentation

```bash
pdoc src -o docs
```
